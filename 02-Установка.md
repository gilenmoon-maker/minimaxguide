# 02 — Установка MiniMax H3 от нуля

## Цель

Получить первый рабочий H3 I2V workflow на **RTX 3070 Ti 8 GB + 64 GB RAM**, а затем перейти к Qwen 8/4-bit и community quant.

> Дата гайда: **19.08.2026**. H3 community сейчас обновляется очень быстро, поэтому перед каждой установкой сверяем README и commit.

---

# 1. Перед установкой

Не удаляй рабочий ComfyUI.

Не меняй Python вручную, если ComfyUI уже запускается.

Сначала проверяем текущую установку, затем обновляем только то, что действительно требуется.

Официальный ComfyUI:

https://github.com/Comfy-Org/ComfyUI

---

# 2. Версия ComfyUI

Для современных H3 community workflows ориентир — **ComfyUI 0.30.0+**. Некоторые экспериментальные сборки тестировались на конкретных версиях и могут требовать более новые или фиксированные версии.

Правило:

> Если README конкретной модели говорит `tested on X`, для первого теста используем X или более новую совместимую версию.

Не считаем версию 0.30.0 универсальной гарантией для всех будущих H3 quant.

# 7. Qwen H3 encoder

Официальный baseline:

```text
qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors
```

Путь:

```text
ComfyUI/models/text_encoders/
```

Важно: это специальный H3 encoder. Не скачивай обычный Qwen3-VL из случайного репозитория и не рассчитывай, что он автоматически заменит этот файл.

Официальный H3 репозиторий также содержит BF16 и INT8 ConvRot encoder-варианты. Для 8 GB мы сначала проверяем более компактные варианты.

# 9. Как импортировать workflow

1. Скачать JSON.
2. Открыть ComfyUI.
3. Перетащить JSON в окно ComfyUI.
4. Проверить названия моделей.
5. Загрузить исходную картинку.
6. Ввести простой prompt.
7. Запустить Queue.

Если ComfyUI сообщает о missing nodes, сначала выясняем название node и источник workflow.

---

# 10. Первый render

Для первого теста:

- 1 персонаж;
- готовый 3D render;
- 4–5 секунд;
- умеренное разрешение;
- простой prompt;
- одно основное действие;
- фиксированный seed.

Цель — не красота, а **первый успешный запуск**.

# 12. Если модель не отображается

Проверь:

```text
ComfyUI/models/diffusion_models/
ComfyUI/models/text_encoders/
ComfyUI/models/vae/
```

Имена файлов должны быть правильными.

После добавления файлов перезапусти ComfyUI.

---

# 13. Если CUDA OOM

Делай по порядку:

1. закрыть другие GPU-приложения;
2. уменьшить разрешение;
3. уменьшить длительность;
4. проверить offload;
5. использовать более лёгкий quant;
6. проверить loader.

Не меняй одновременно H3 + Qwen + workflow + sampler.

---

# 14. Если RAM почти закончилась

64 GB — большой запас, но не бесконечный.

Проверь:

- Windows Task Manager;
- pagefile;
- другие приложения;
- объём offload;
- размер конкретного checkpoint.

Если Windows начинает активно использовать pagefile, генерация может стать экстремально медленной.

# 16. W4A8 — отдельная установка

Источник:

https://huggingface.co/starsfriday/MiniMax-H3-w4a8

Loader:

https://github.com/starsFriday/ComfyUI-W4A8-Loader

Автор указывает отдельный custom loader и comfy-kitchen. Обычный diffusion loader использовать нельзя. citeturn0search1turn0search3

Checkpoint:

```text
minimax_h3_fl2va_pruned_w4a8_mixed.safetensors
minimax_h3_ref2va_pruned_w4a8_mixed.safetensors
```

Заявленный размер: **12.54 GB**. citeturn0search1

### Важное ограничение

README loader указывает Linux, NVIDIA SM80+, Python 3.10+, CUDA 12.8+ и соответствующий PyTorch/toolkit; Windows installer не поддерживается. Поэтому на Windows это **не первый вариант**, даже несмотря на то, что RTX 3070 Ti архитектурно относится к Ampere/SM86. citeturn0search1turn0search3

---

# 17. SVDQuant

Источник:

https://huggingface.co/Aero-Ex/MiniMax-H3-SVDQuant

Это отдельная экспериментальная W4A4/SVDQuant toolchain.

Автор заявляет около **11.1 GB** для rank-64 act-aware варианта и указывает INT8 activation compute как интересный вариант для Ampere. citeturn0search11

Ставим после обычного INT4.

---

# 18. GGUF

GGUF устанавливается отдельно.

Например:

https://huggingface.co/molbal/MiniMax-H3-GGUF

molbal указывает Q4_0/Q8_0/Q8_CR/U16G и отдельные требования для Q8_CR/U16G. citeturn0search0

Не смешивать GGUF loader разных авторов.

---

# 19. Правильная структура установки

Не складывай все эксперименты в одну заменяемую папку без понимания loader.

Минимум:

```text
ComfyUI/models/
├── diffusion_models/
│   ├── official/
│   ├── int4/
│   └── experimental/
├── text_encoders/
└── vae/
```

Если ComfyUI не видит вложенные папки, используй его стандартные пути/extra_model_paths вместо самовольного изменения структуры.
